# Project guidance

- Consult `.cursor/project-context/` for relevant project decisions and `.cursor/lessons-learned/` for related recurring failures. Read root `MEMORY.md` when it exists and is relevant. Record durable decisions and reusable lessons in those locations.
- Use a project-local skill when the user invokes it or its workflow helps the task. Ordinary edits do not require a fixed skill sequence. If a needed Matt Pocock skill is missing, run `bash scripts/install-matt-pocock-skills.sh`.
